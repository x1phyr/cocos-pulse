01 / HEADLINE

cocos4 苏醒：#367 Web DPR 启动可配合入，#373 接 #371 按需分配 Graphics 缓冲，再挂 #374 索引缓冲泄漏

沉寂多日的 cocos4 在这一窗口连出三响，内存占用与高分屏清晰度两条线一起动起来了，值得盯。#367（LinYunMo，+284 / −12，llsansun 于 10-22 19:15 CST 合入 → v4.0.0）让 Web 渲染的 DPR 上限可经启动 settings 配置：读 screen.maxDevicePixelRatio，预设 Performance=1 / Balanced=2 / Quality=4，默认仍封顶 2；有效 DPR 取 min(浏览器 DPR, 配置上限)，仅启动时消费、非 Web 忽略。配对文档 docs#3330 今早 09:58 CST 由 star-e 合入。昨天刚开的 #371 当天 15:00 CST 就有 Tianze-Chen 的 #373（+122 / −24，OPEN）：Graphics 子模型不再预分配约 2.25 MiB，按块数据起步、按需翻倍扩容、不缩回。同作者系官方 llsansun 17:43 CST 再开 #374：MeshRenderData.clear() 在 Web / 小游戏路径销毁顶点缓冲却漏销毁 _indexBuffer，每次 clear 泄漏一块 GL buffer。

02 / SIGNAL

cli beta 再收 #1005 import map，新挂 #1006 首次选中 2D 粒子不播；engine #19274 提 tick 限速改造

cli 的修补继续砸在 v0.2.0-beta.0 上，分支领先 main 从 4 增至 5；engine 主仓仍零提交，但来了一份写得很厚的帧调度提案。上期 OPEN 的 #1005（DecviL，+200 / −17）于 10-22 12:25 CST 由 wuzhiming 合入：脚本热重载时以 no-store 刷新浏览器场景 import map，修新建脚本后组件加载失败。傍晚 18:34 CST bofeng-song 新开 #1006（+75 / −1，OPEN，关联禅道 1126）：预览开启的 ParticleSystem2D 场景加载后焦点回调跑了、编辑器开始连续 tick，发射器却仍 idle——引擎 focus hook 只重置 preview 关闭的系统；修复后在正常 focus 回调后再启动仍 inactive 且 preview 开启的 2D 发射器。main 无新提交，#1001 [break] 仍挂。engine 侧 tangkaikk 10:40 CST 开 #19274（并镜像 cocos4 #372）：指 Engine::tick 用历史平滑耗时算 sleep 会在假设条件下偏到约 64.5 FPS，提议 steady_clock + 绝对截止时间并理清与 Swappy / VSync 职责；尚无真机数据、无 PR。
