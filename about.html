关于 Cocos Pulse

听引擎的心跳 —— Night Dispatch 风格的 Cocos 生态日刊门户。

WHAT // 这是什么

POSITIONING

Cocos Pulse 不是信息堆砌，是心跳速览。面向 Creator / 引擎 / 工具链关注者，把论坛热点与 GitHub 窗口内动静压成一页可读的 Night Dispatch。

品牌标题 COCOS / PULSE，标语「听引擎的心跳」。视觉沿用霓虹编辑风：Orbitron 标题、扫描线、斜切 masthead、ticker 与彩色 pills。

SOURCES // 信源

OFFICIAL + GITHUB
  • forum.cocos.org — 官方与社区帖（摘要级）
  • cocos/cocos-engine — Creator 3.x 引擎仓
  • cocos/cocos4 — 下一代引擎
  • cocos/cocos-cli — 编辑器 / 工具链
  • cocos/cocos-docs — 文档仓

CADENCE // 更新节奏

WEEKDAYS

工作日约 09:56 CST（Asia/Shanghai）出刊。覆盖自上期以来约 24–48h 窗口。周末与节假日可休刊。

DEPLOY // 静态模型

NO DB · GITHUB PAGES

纯静态 HTML / CSS / JS，无构建步骤、无数据库、无服务端渲染。适合 GitHub Pages（项目站路径 /cocos-pulse/）或任意静态宿主。

  • 日刊落在 issues/YYYY-MM-DD.html
  • 根目录同名文件做薄跳转，保证旧链不断
  • 相对路径引用资源，子路径部署可用
  • 新增刊时同步首页「今日/近刊」、归档行、可选专题回填

详见仓库内 DESIGN.md。

DEPTH // 论坛深度

SUMMARY-LEVEL

论坛内容只做摘要级：标题 + 一两句速览 + 原帖链接。不转载全文，不当技术结论的氛围帖会标明「当社区氛围条」。仓库侧保留真实 PR / issue URL 与一句话说明。
