国庆当天官方「全版本更新：X」：Dashboard 一键升 Creator · Build All 发全平台

国庆第一天（10-01 上午）官方 @wanlai_sud 没放假，直接把 Dashboard 与 Creator 一起推了一遍，连发两帖：COCOS 全版本更新：X（约 17 楼 / 1370）+ 全版本升级指南（约 27 楼 / 1632）。四刀：Dashboard 新增 Creator 升级能力（联网自动升到 2.2.2）、集成 OpenPaaS 入口、登录即自动注册并关联 SUD 账号、Creator 全版本新增「一键发布到全平台：终端 / 应用 / 场景」。口径是不改 Creator 版本号、不影响既有研发流程，只新增发布平台；2.x / 3.x 全部版本按计划陆续推送，11 月起陆续打开「发布到应用」（SUD 已支持的 3000+ 应用）与「发布到场景」（GI / AD / AI）。长文还抛出 xOS（约 3000 个 API 超集、Farewell if-else）与单文件流式包 .sp，结尾一句「开发者需要做什么——enjoy」。
