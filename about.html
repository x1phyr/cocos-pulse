关于 Cocos Pulse

听引擎的心跳 —— Night Dispatch 风格的 Cocos 生态日刊门户。铁粉速览，不灌水。

STORY // 产品故事

WHY PULSE

Cocos Pulse 不是 Discord 瀑布流，也不是「今日热帖」搬运工。它把论坛热点与 GitHub 窗口内动静压成一页可读的 Night Dispatch：三条头条、论坛摘要、仓库心跳、版本表——工作日早上一眼扫完。

品牌标题 COCOS / PULSE，标语「听引擎的心跳」。视觉沿用霓虹编辑风：Orbitron 标题、扫描线、斜切 masthead、ticker 与彩色 pills。

诚实约束：不虚构日刊、不编造 PR。专题页可以跨日聚合，但必须标「聚合（截至 …）」并回链真实来源。

CADENCE // 更新节奏

WEEKDAYS 09:56 CST

工作日约 09:56 CST（Asia/Shanghai）出刊。覆盖自上期以来约 24–48h 窗口。周末与节假日可休刊。

专题页可另做「近 2–4 周」回填，但不会伪装成新的日刊。近刊列表只列真实已发期号。

DEPTH // 内容深度

FORUM = SUMMARY

论坛默认摘要级：标题 + 一两句速览 + 原帖链接。不转载全文。不当技术结论的氛围帖会标明「当社区氛围条」。

关键帖（如 PinK Alpha、UI 手搭论战、peanut-pod）可加深到：楼主核心观点 + 官方/高赞一句——仍非全文 dump。

仓库侧只保留真实 PR / issue URL 与一句话说明；静音如实写「无新 commit」。

DEPLOY // 静态模型

NO DB · GITHUB PAGES

纯静态 HTML / CSS / JS，无构建步骤、无数据库、无服务端渲染。

  • 仓库：github.com/x1phyr/cocos-pulse

  • 日刊：issues/YYYY-MM-DD.html；根目录同名薄跳转保旧链
  • 相对路径引用资源，子路径部署可用
  • 详见仓库内 DESIGN.md · 站务见 changelog.html
