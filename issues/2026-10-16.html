01 / HEADLINE

cli #990 大拆分：私有编辑器 runtime 抽走 · standalone CLI 保住 104 个 MCP · 配对 α.44

昨天九连合刚落袋，今天 main 零合入，但窗口内最大一枪来了：DecviL 晚上抛出巨型 breaking PR，把私有 scene 编辑器 runtime 整段抽走。#990[break] refactor(scene)——+6508 / −59313、381 文件，约 21:06 CST 开出，今早仍 OPEN。把 Camera、Gizmo、Operation、PreviewPlay、拖拽落点、浏览器预览、模拟器会话等编辑器专用服务抽到独立仓 pink-scene-editor-extension；CLI 侧留下 scene/Prefab/节点组件、撤销重做、资源脚本、烘焙后端与离屏 WebGL/Canvas，并保住全部 104 个 scene MCP（含 13 个探针/光照图工具）。公开入口收敛为 cocos-cli/host/...，配对 PinK runtime 版本写死 0.0.1-alpha.44。昨日新开的 #987/#988/#989 落盘一致性三连仍 OPEN；#983 3D 平移、#985 四层 API 文档未合。
