01 / HEADLINE

PinK 0.0.2.0 Beta 公测免码上线：从「蹲码」到官网直下 · 首席体验官×抓虫大赛同步开

周末最大新闻没有悬念：官方终于把本月转 Beta 的承诺落地了。PinK Beta 版发布（万籁@SUD，10-25 00:53 CST，置顶，26 楼 / 1020+）宣布 0.0.2.0 Beta 进入公测，官网下载、不再需要激活码；macOS 因 Bundle ID 改为 global.sud.pink 需卸载重装并备份，Windows 可覆盖。Changelog 亮点：Chat 新增 96 个 PinK 原生工具入口；会话可独立绑定场景、写入前确认与草稿冲突检查；BYOK Agent 接入会话级工具发现；Assets 支持 ZIP 资源包导入导出；场景编辑 / 编辑器内播放 / 资源预览 / Animation Graph Motion / 模拟器统一接入独立场景运行时；激活码校验默认关闭。楼下 yuphon 夸体验但喊 token 贵，worm 问是否还支持「手动挡」2.4/3.8 式开发，有人贴 3.8.8 项目「提示不支持」。同日开的 首席体验官×抓虫大赛 已收到 weijinda「Start failed」复现，官方 max 定位到 exFAT 盘、建议先换 NTFS。

02 / SIGNAL

cocos4 周五连收 #373/#379/#381，engine 镜像 #19275；cli 新挂 #1007 [break] 与 main #1008

上期还 OPEN 的 Graphics 与索引缓冲两条线，周五下午就全部落地；cli 周末则一边在 beta 上拆 runtime，一边在 main 补动画三连修。cocos4：上期 OPEN 的 #373 于 10-23 11:23 CST 由 llsansun 合入（→ v4.0.0），#371 随即关闭；MagicXHouse 同日 15:08 CST 合 #379（+4），在 MeshRenderData.clear() 销毁并置空漏掉的 _indexBuffer，关闭 #374，并镜像合入 engine #19275（→ v3.8.9）。晚间 qiuguohua 合 #381 避免微信触摸事件重复。周六 LinYunMo 新开 #382（+1026/−207，OPEN）序列化自定义字体族、恢复原生字体别名。cli：周五傍晚 DecviL 开 #1007 [break] 发布共享浏览器 runtime 与 host capabilities（→ v0.2.0-beta.0，+2154，OPEN）；周六 looopmax 在 main 开 #1008 修动画状态组件枚举、AnimationClip 引用退化与设计分辨率改写编辑视口（禅道 1464/1426/1361，OPEN，周一仍有更新）。#1006 粒子、#1001 [break] 仍挂；beta 领先 main 仍 5 条，无新 Release。
