01 / HEADLINE

PinK 0.0.1.39 Alpha 发布 · cli α.44 转正 Latest · 官方首次写明「本月转 Beta、公测免码」

上周大家在 .38 公告楼下天天问 39 来没来，周一下午它终于来了，而且公告尾巴第一次把 Beta 的时间点写进了正文。PinK 0.0.1.39 Alpha（10-19 16:26 CST，wanlai_sud）更新日志：图形项目数据设置、项目资源及依赖导出 ZIP、API 构建打标、Button 组件级事件 API，编辑器内预览播放 / 暂停 / 单步逻辑调整（兼容性变更），外加 2D 网格视口同步、隐藏预览 Canvas 重复渲染、SkinnedMeshBatchRenderer 递归、HDR 浮点 RT、骨骼重建后 GPU 骨骼缓冲未重绑、V8 Promise / 音频迭代器失效等一串 cocos4 修复——与当天 17:32 CST 转正的 cli 0.0.1-alpha.44 Release（#961/#965/#960/#969/#967/#972/#976～#979/#995）基本一一对应，印证了 α.44 changelog 里「最低 PinK .39」。公告结尾：「PinK 将于本月转入 Beta 版……Beta 版将开启公开测试，不再需要激活码。」楼下 23 楼仍是一片求码，也有人「不等码了 等 beta 了」，还有人翻出「这个月还剩两周」。

02 / SIGNAL

Beta 版本号三连：cocos4 tag 4.0.0-beta.0 · cli #998 切引擎依赖 · #994 抬到 0.2.0-beta.0

PinK 公告里的 Beta 不是空话，GitHub 周一下午四十多分钟里，引擎和 CLI 的版本号一起跨进了 beta 段。cocos4 由 star-e 开 #369 bump version to 4.0.0-beta.0（14:15 CST 合入，仅动 package.json / lock），机器人 #370 14:31 跟进生成代码，tag 4.0.0-beta.0 就打在这次提交上（尚无 Release，Latest 仍 α.35）。cli 侧 #998 把 repo.json 引擎 tag 从 4.0.0-alpha.36 改成 4.0.0-beta.0（14:57 CST），一分钟后上期还 OPEN 的 #994 合入，CLI 版本正式变成 0.2.0-beta.0，并新出 v0.2.0-beta.0 分支；中午还有 #997 把 α.44 分支上的 #995（构建前重置资源缓存）回灌 main。

03 / FORUM

论坛：OpenPaaS 上架冲刺季开跑 · 2.4.15 打包 30→5 分钟补丁 · Game Agent 0.4.1 叫板 MCP

除了 .39，周一论坛还有三条线：官方拉人上架、老版本玩家自己动手修编辑器、第三方 Agent 继续抢 PinK 的地盘。有奖活动｜OpenPaaS 上架冲刺季（10-20～11-19）：10 月内正式上架前 50 名送鼠标垫，IAA / IAP 上架数与阿 / 英 / 俄多语种榜各取 Top 5，报名进 VIP 技术群，每周五 18:00 公布榜单；楼下有人反映更新 OpenPaaS 版 3.8.8 后安卓包的 Cocos 图标去不掉。【一键补丁】creator 2.4.15 打包 30→5 分钟：200+ bundle 项目让 AI 扒编辑器，瓶颈在自动图集 initTexturePacker，楼主已放补丁；楼下呼吁「官方还是开源编辑器吧」。Game Agent 0.4.1 长文对比 MCP / Codex，主打内置 CLI 让 Codex、Claude Code 委托它操作场景；PinK 为何开发如此缓慢？ 一天从 7 楼涨到 24 楼。
