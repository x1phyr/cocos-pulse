01 / HEADLINE

双 beta 落地：cocos4 4.0.0-beta.0 + cli 0.2.0-beta.0 · 周一合入潮 #1020–#1025

周末到周一，仓库把「还在等 beta 挂牌」这件事一次性办完。cocos4 于 11-02 06:23 CST 发布 4.0.0-beta.0（同日补发 α.36），changelog 指向 bump #369；窗内另合 #389 WebGL buffer resize 跟真实 BUFFER_SIZE 对齐，以及机器人 #388/#390；llsansun 的 #395 已把主干 package 再抬到 beta.1 字样。cli 同日 09:07 CST 挂 0.2.0-beta.0（内含引擎钉到 4.0.0-beta.0 的 #998 等），随后周一又把上期还 OPEN 的 #1021–#1023 与 #1020/#1024/#1025 一并合进 main——合完 main 相对 beta.0 仍领先 14 条；新开 #1026 Prefab 跨 runtime 同步。engine / docs 窗内零合入。
